## 〇、安全红线（所有 Agent 必须遵守，写入代码注释与报告声明）

| # | 红线 | 技术落实 |
|---|------|---------|
| S1 | 禁止向非 localhost 发起任何网络请求 | PoC/验证代码中网络调用仅允许 `127.0.0.1`/`localhost`；统一走 `_assert_local(target)` 守卫函数，否则抛 `UnsafeTargetError` |
| S2 | 禁止修改用户代码 | 修复建议一律生成为 Diff 字符串，不落盘到源文件 |
| S3 | 禁止删除文件 | 不提供任何删除 API；画像"删除"仅指删除画像库中该开发者数据 |
| S4 | 禁止真实攻击 | PoC 默认只生成字符串（模式 A）；本地 crypto 计算（模式 B）；靶场验证（模式 C）仅 Docker 隔离环境且需 `--verify` 显式开启；无 Docker 自动降级为"特征匹配模拟验证" |
| S5 | PoC 数据 30 天自动清理 | 攻防报告与 PoC 存 SQLite 时记录 `created_at`，提供 `fp-sentinel attack-purge` 命令清理过期数据 |
| S6 | 画像隐私 | 开发者身份默认匿名化（SHA256 别名）；本人可查（`profile me`）；提供 `profile forget <alias>`；报告头部固定声明"仅用于培训与能力提升，不用于绩效考核" |
| S7 | 报告输出白名单 | 所有报告文件只写入 `--output` 指定目录（默认 `./reports/`），拒绝路径穿越 |
| S8 | 联邦梯度加密传输 | `privacy.crypto.GradientEncryptionEngine` 强制加密，传输前安全检查 |
| S9 | 规则共享自动脱敏 | `privacy.rule_sharing.DesensitizationEngine` 多层清洗，敏感字段替换为 `[REDACTED]` |

**运行环境**：解释器 `C:\Users\lenovo\AppData\Local\Microsoft\WindowsApps\python.exe`（3.12.10）。Windows Git Bash/PowerShell。Docker 可能不可用——所有依赖 Docker 的功能必须实现可用性检测与降级路径。
