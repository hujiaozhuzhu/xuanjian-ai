## 遗留问题（未修，超出最小修复授权）

1. **CLI 单文件 + auto 语言检测失效**：`scan <单文件>` 默认 `language=auto` 时，`ScannerManager._detect_language`（fp_sentinel/scanners/manager.py:121-166）对文件路径 `os.walk` 无输出、构建文件探测全部落空，最终返回默认 `"java"`，导致 semgrep/findsecbugs（均未安装）被选中、PythonScanner 不参与，结果 0 检出。需显式 `--lang python --scanner python_scanner` 才正常。属既有设计局限，建议后续为单文件路径增加按扩展名识别。
2. **py.auth.no_csrf 粗粒度**：对靶场 `app = Flask(__name__)` 实例化行即报 MEDIUM，不在 expected 列表内（extra 发现）。提示合理但定位过粗，建议规则收敛到路由装饰器级别。
3. **js.node.ssrf 对内部相对 URL 误报**：`web/static/app.js L208`（相对路径 API 调用）被判 HIGH。建议对以 `/` 开头的相对 URL 增加抑制。
4. **Python 靶场 expected-findings.json 无 safe 条目**：脚本依赖 `FALLBACK_SAFE_LINES` 硬编码 7 条 safe 行。功能正确，但与 JS 靶场结构不一致，建议补齐 safe 条目。
