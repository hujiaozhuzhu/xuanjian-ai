# C3 - Industry Rules, Cross-Industry Comparison & Updater

## Industry Rules Engine
Each industry has 2-4 specialized scan rules targeting:
- API authorization (internet)
- Transaction integrity (finance)
- Citizen PII protection (government)
- PLC protocol security (industrial control)
- Medical device security (healthcare)
- Child privacy (education)
- SIP/Diameter security (telecom)
- SCADA intrusion (energy)
- Signal system manipulation (transportation)
- Claims logic bypass (insurance)
- HFT latency fairness (securities)

## Cross-Industry Analyzer
Compares all 11 industries across 6 dimensions:
1. Average repair cycle
2. Vulnerability density
3. Critical vulnerability ratio
4. Top category dominance
5. Compliance requirement count
6. Industry scenario count

Produces ranked reports with best/worst identification per dimension.

## Data Updater
- S1 compliant: External sources disabled by default
- Built-in data import (always works offline)
- Configurable retention: Default 180 days (S5)
- DB path: ~/.xuanjian/benchmark.db (S7)
- External update stub returns failure (safety)
