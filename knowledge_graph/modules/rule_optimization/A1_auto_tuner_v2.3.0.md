## 一、功能概述

规则自动调优模块通过分析历史误报数据，智能调整三层过滤器（L1/L2/L3）的判定阈值，
降低整体误报率不低于15%。

## 三、核心设计

### 3.1 算法原理

1. **统计分布分析**: 计算误报样本置信度的均值(mean)和标准差(std)
2. **加权移动法**: 目标置信度 = mean + 0.5 * std，向该方向逐步移动
3. **安全边界约束**: 阈值始终在 `[min_confidence, max_confidence]` 范围内
4. **步长限制**: 单次调整不超过 `MAX_ADJUSTMENT_STEP = 0.05`

### 3.2 三层阈值配置

| 层级 | 默认阈值 | 最小值 | 最大值 | 说明 |
|------|---------|-------|-------|------|
| L1 规则过滤 | 0.70 | 0.50 | 0.95 | 路径白名单、代码忽略标记 |
| L2 上下文过滤 | 0.50 | 0.40 | 0.90 | 安全守卫检测、Java分析 |
| L3 ML过滤 | 0.70 | 0.50 | 0.95 | 历史基线、启发式预测 |

### 3.3 数据流

```
历史误报数据采集 → 按层级分组 → 计算统计量 → 推导最优阈值 → 应用/回滚
      ↓
  JSON文件 / 目录批量 / 单条添加
```

## 四、API 说明

### AutoTuner 类

| 方法 | 说明 |
|------|------|
| `load_fp_samples(path)` | 从JSON文件/目录加载误报样本 |
| `tune_layer(layer)` | 对指定层级调优 |
| `tune_all_layers()` | 调优全部三层 |
| `apply_thresholds(report)` | 应用调优结果 |
| `rollback(steps)` | 回滚到之前的阈值 |
| `save_report(report)` | 保存调优报告 |
| `save_thresholds(path)` | 保存阈值配置 |
| `load_thresholds(path)` | 加载已保存的阈值 |
| `generate_synthetic_fp_data(count)` | 生成合成测试数据 |

### TuningResult 数据模型

| 字段 | 说明 |
|------|------|
| `layer` | L1/L2/L3 |
| `previous_threshold` | 调整前阈值 |
| `new_threshold` | 调整后阈值 |
| `adjustment` | 调整量 |
| `fp_samples_analyzed` | 分析的样本数 |
| `predicted_reduction_pct` | 预计误报降低率(%) |
| `confidence` | 调优置信度(0-1) |

## 五、误报降低率计算

预期误报降低率基于以下逻辑：

```
降低率 = (在旧阈值之上且在从新阈值之下的样本数) / 总样本数 × 80%
```

系数80%是因为部分样本可能被其他层级过滤器拦截。

目标：**整体误报率降低 >= 15%**

## 八、安全保障

1. **安全边界**: 阈值始终约束在 `[min, max]` 范围
2. **步长限制**: 每次调整不超过 0.05，防止跳跃过大
3. **回滚机制**: 支持多级回滚，调优历史完整记录
4. **样本量门槛**: 至少 10 条误报样本才执行调优
5. **置信度过滤**: 仅当调优置信度 >= 0.5 时才应用变更
